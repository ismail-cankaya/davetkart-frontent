# `src/i18n.ts` · `LanguageSwitcher` · `useDocumentDirection`

> **Faz:** 19.20 — `FE-01` · **Karar:** K220 · **Test:** `npm run verify:render` → *Dil kapsamı*

## Neden

Seçici on dil sunuyordu; çevrilmiş olan yalnızca üst menü ve ana sayfa (72 anahtar). Almanca seçen
ziyaretçi ödeme adımında Türkçe görüyordu, Arapça sayfayı RTL çevirip metni Türkçe bırakıyordu.
Arayüz veremediği bir sözü vermesin: yalnızca `tr` ve `en` sunulur (hata sözlüğü de bu ikisinde).

## Desen

- **Tek kaynak:** `SUPPORTED_LANGUAGES`. Seçici, `supportedLngs`, `isSupportedLanguage` ve
  `<html dir>` (`getLanguageDirection`) hepsi ondan okur.
- **Varsayılan:** `DEFAULT_LANGUAGE = 'tr'` — eksik anahtar, desteklenmeyen tarayıcı dili ve eski
  kayıt aynı yere düşer (`fallbackLng`). Önceden `en`'di; yarım İngilizce + Türkçe karışımı yerine
  tutarlı Türkçe sayfa.
- **Eski kayıt:** `storedPreference` algılayıcısı `localStorage['davetkart-language']`'ı okur;
  desteklenmeyen bir kod (`de`) **tarayıcı diline değil** `tr`'ye çözülür, önbellek onu `tr` ile ezer.
- Diğer sekiz dilin dosyaları `src/locales/` altında durur, içe aktarılmaz (pakete girmez).

## Bir dili geri açmak

1. Çekirdek akış (kayıt → panel → editör → ödeme → hesap) o dile gerçekten çevrilmiş olmalı;
   `npm run verify:i18n` tabanı bunun ölçüsüdür (`docs/rehber/scripts/verify-i18n.md`).
2. `errors.json` o dilde yazılmalı (`verify:errors`).
3. `i18n.ts`'te içe aktar, `resources`'a ekle, `SUPPORTED_LANGUAGES`'a satır ekle (`ar` → `dir: 'rtl'`).
4. `verify-render.tsx`'teki `'tr,en'` beklentisini güncelle.

## Sık hata

- Seçiciye dil eklemek ama `resources`'a eklememek: seçilir, `fallbackLng` ile Türkçe görünür.
- `window.localStorage`'ı doğrudan okumak: gizli sekmede istisna atar; `lookup` `try` içinde.

## Nasıl denenir

Tarayıcıda `localStorage.setItem('davetkart-language','de')` → yenile → sayfa Türkçe, seçicide
iki dil, kayıt `tr`. Otomatik: `npm run verify:render`.
