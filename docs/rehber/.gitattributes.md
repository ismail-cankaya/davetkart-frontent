# `.gitattributes` — satır sonları ve ikili dosyalar

> Faz 21.18 · `ARC-07` · K275.

## Neden?

Frontend'de `.gitattributes` yoktu; satır sonunu her geliştiricinin `core.autocrlf` ayarı belirliyordu (bu makinede
`true`: depoda LF, diskte CRLF). Sonuçlar: (1) bir dosyayı Write/Python ile LF yazmak `git diff`'te bütün dosyayı değişmiş
gösterebiliyordu, (2) `git add -A` yüzlerce dosyayı sürükleyebiliyordu (docs `CLAUDE.md` §7 "CRLF tuzağı"), (3) backend'den
kopyalanan `src/contracts/error-codes.json` diskte backend'inkinden **bayt bayt farklıydı** (CRLF, 4381 B; backend LF, 4209 B).

## Kural

```gitattributes
* text=auto eol=lf
*.png *.jpg *.webp *.mp4 *.webm *.woff2 *.glb *.ico binary   (her biri ayrı satırda)
```

- `text=auto`: Git içeriğe bakıp metin mi ikili mi karar verir; metin depoya LF girer.
- `eol=lf`: metin dosyaları **çalışma ağacına da** LF yazılır; `core.autocrlf` ne olursa olsun. Backend ve docs depoları
  zaten aynı kuralda (`* text=auto eol=lf`).
- `binary`: ikili dosyalarda dönüşüm ve metin farkı yok (bugün depoda woff2 95, jpg 85, mp4 64, webm 63, webp 39, png 24).

## Çalışma ağacını LF'ye çevirmek (isteğe bağlı, İsmail)

Yalnızca **temiz ağaçta** ve **Vite kapalıyken** (dosyalar yeniden yazılır):

```powershell
cd D:\Projects\davetkart\davetkart-frontent
git status --short                 # boş olmalı
git checkout-index --force --all   # indeksteki her dosyayı .gitattributes kuralıyla (LF) yeniden yazar
git status --short                 # yine boş olmalı
git ls-files --eol | Select-String "w/crlf" | Measure-Object   # 0
```

Sonra editörün (VS Code `files.eol`) yeni dosyalarda LF kullanması önerilir; `.gitattributes` zaten depoya girişte LF'ye
çevirir.

## Sık yapılan hatalar

| Hata | Sonuç |
|---|---|
| `* text eol=lf` (auto'suz) | İkili dosyalar metin sanılıp bozulabilir |
| Yalnızca `core.autocrlf` ile çözmeye çalışmak | Kişisel ayar; depo herkes için aynı kuralı taşımaz |
| Kural eklendikten sonra çalışma ağacı CRLF'ken `git add -A` | `eol=lf` girişte yine LF'ye çevirir: fark yok (eski tuzak kapanır) |
